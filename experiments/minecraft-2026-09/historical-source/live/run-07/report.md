# 全员换代后：工作重新接上了，理解没有原样继承

2026-09-19（北京时间）｜历史通道关闭世界的单次后继代探索

**三个全新 Run 没有旧 conversation、Message 或 checkpoint 输入，仍重新利用了前代库存、延续农业，并通过新建公共储物发生物资接续。但接手伴随重复建设、未被使用的供给、错误解释和不合格的施工自报。观察支持这一次有限的工作连续性，不支持“世界足以替代所有记忆”，也不等于整体协作已经收敛。**

## 本次只换了什么

从 run-06/r17 最终世界和已停止的数据库建立独立副本。前代三个 Run 已结束；本轮使用三套全新 Run/native session ID，保留同名 bot 的位置、背包、装备，以及耗尽的地表石头、已有建筑、容器和农作物。不补资源，不修地形，不告知新人前代做法或错误。

工具、提示和 Minecraft adapter 与上一轮逐字节一致。仍仅开放 read_work / mc_observe / mc_action，其他项目历史及通用文件工具不暴露。原始历史在离线数据库和观察者 CLI 中保留，worker 不可读。共同目标、Minecraft 先验和各自本轮会话仍存在；不是消除全部知识或 OS 安全隔离。

开跑前扫描范围内方块、容器与源快照一致，三个 bot 存档逐字节一致；启动推进1 tick后冻结，用户开录后放行。全部518次真实 provider 请求输入审核通过；三个首请求都只有 system/user 两条消息，没有历史 assistant 对话，工具集合均为上述三项。全程没有新 Message/checkpoint，也没有操作者补充背景或纠错。

## 观察到的接手过程

### 1. 同一个世界，新人先形成了不同地图

A找到旧主箱 (0,-60,0)，19:19:34Z 已存入7原木。B、C却将公共箱和工作台判为缺口。C于19:18:27Z声称附近没有工作台、箱子、熔炉，随后在 (10,-60,-5) 建工作台、(10,-60,-6) 建箱；B在旁边 (9,-60,-6) 加箱并使用新工作区。

C此前的混合搜索同时请求 chest/crafting_table/furnace 和大量 dirt 等，返回列表上限24块，被近处泥土等占据。列表没有某种设施不等于24格范围不存在设施。工具已写明有限覆盖，但它仍把未返回扩大为不存在。重复建设确实发生；新工作区后来有实际使用，也不能把它全算作无价值。

B没有永远停留在最初地图：19:28:06Z和19:29:20Z分别把2原木存入旧副箱 (3,-60,2)。这是从新工作区重新接触前代设施的实际行为证据。

### 2. 前代与本代的小麦汇合成一份面包

C于19:23:56Z向新箱存入1小麦。A于19:25:39Z取出这1份，又在19:25:46Z从旧主箱取出前代留下的2份；19:25:48Z合成1面包，19:25:50Z存回旧主箱，主箱面包14→15。

这条链同时有明确的请求、容器前后状态、背包结果与最终存档支持，是真实跨代物资接续。它不需要继承小麦原作者的解释，也没有 Message 指定交接。

### 3. 推断出别人的工程，不等于供给有用

A把B/C挖土理解为“基地主要工程是向东/向下开挖”，从旧主箱取料制作石铲，于19:23:16Z存入新箱。三人的完整 transfer 记录中，之后没有人取出这把铲子，最终它仍在箱里。

这是根据他人痕迹做供给的行为，但“这把铲子帮助同伴推进了工程”没有成立。不能把意图、入库和有效协作当成同一件事。

### 4. 操作成功了，因果解释依然可以错

C多次放置失败后，于19:25:03Z宣称发现 `face` 指向支撑方块的规则，之后继续搭棚。代码核对：现有 place 分支自行按固定邻接顺序选择支撑，根本不使用用户传入的 face；face 用于其他动作。这不是本轮改动。

因此“改 face 导致成功”的解释不成立。后来C又总结箱子/工作台正上方不能放置；日志确有相关失败，但没有控制实验确认它的普遍原因，不能照收为 Minecraft 世界规则。部分错误也可能与现有 adapter 行为及交互语义有关，实验没有中途修接口。

### 5. 造出了棚，不等于造出了可站立的庇护所

C最终声称建成约3×2、可安全站立的有顶空间。存档核对：该处地面方块在 y=-61，顶在 y=-59，中间净空约1格；当前本地1.21.1实体数据中 player.height=1.8。不能认定它是普通站立可用的庇护空间，也没有完成真人或bot通行验收。

顶部和墙体是真实建造结果，但“共同目标中的可用庇护所已经完成”仍是未经验证且受几何事实反驳的自报。这一项保留为失败，不用方块增加替代功能达成。

## 这一刀回答了什么，没回答什么

**它排除了“只有这三个上一代 Run 自身的当前会话，才能维持这一次短期推进”这一必要性解释。** 换掉全部会话后，新人仍能利用世界遗留并形成部分材料接续。世界保存了设施、资源和后果，足以支持这次有限的重新进入。

但没有继承一张正确完整的地图，也没有继承准确的因果模型或前代意图。重复建设、错误归因、闲置工具、资源消耗和不合格棚屋同时存在。因此更准确的描述是**可重新进入、可局部接续，且有成本和错误**，而非无损协作或认知收敛。

限制：仅一个后继代、单一模型家族；没有从相同起点保留旧会话继续的配对，不能量化换代的纯因果成本。先前消融同时关闭多种叙述通道，本轮也不能分别估算其价值。模型Minecraft先验、共同目标、动作接口、保留的bot位置/物品仍提供强支架。起点因前代而改变；新人说“没有石头”与前代同句，不自动算历史传播或同一种错误。上轮缺失的时钟/难度信息和技术设施限制本轮仍保留。
