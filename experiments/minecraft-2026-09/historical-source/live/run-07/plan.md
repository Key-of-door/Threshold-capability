# 历史关闭后的全员换代

工作参考，可按技术现场调整；不改 Threshold core。

## 要观察什么

上一轮 r17 的三个 worker 在没有 Message/checkpoint 通道的条件下推进了工作，但各自保留了当轮会话。现在结束这条会话连续性，观察三个全新 Run 能否仅凭相同简短目标、模型先验、身体状态和可重新检查的世界继续。

## 起点与变量

- 从 run-06/r17/snapshots/final 和已停止服务的数据库建立独立副本；源文件保留。
- 三个旧 Run 已结束。使用三个全新 Pi session，仍为 --no-session，不恢复旧 conversation。
- 保留同名 bot 的位置、背包、装备以及全部世界后果。不补资源，不修建筑，不重置身体。
- 沿用相同模型、上下文/输出配置、工具、提示、预算、窗口串行、双 trace、快照和 CLI 录制设施。
- 仅开放 read_work / mc_observe / mc_action。历史仍存于数据库供观察者核对，不进入模型输入。
- 不注入前代解释、摘要、角色分工、错误纠正或实验结论。
- 不补充上轮缺失的静态规则或世界时钟，以免同时改变信息条件。

## 预算和开跑

三个 Run，各最多12段；合计500模型回合软收尾、600硬停止，25/30分钟软/硬时间，其他 token 边界沿用上一轮。世界启动后冻结，核对方块、容器、bot 存档和 gameTime，再等待用户连接并确认前台开录。CLI由实验脚本记录。

## 观察重点

新人实际看到了什么，何时识别已有设施和可用物资；是否继续、忽略或撤销前代成果；哪些意图无法从物质遗留恢复；错误解释消失还是独立重生；前代损失如何约束新人；任务推进与正确理解是否再次分离。

首次动作不等于首次有效工作。物品转移不等于生产。同类物品混堆不做超出证据的来源归因。相同错误不自动意味着历史传播。

## 限制

这是单次后继代探索，没有从同一状态保留旧会话继续的并行对照，因此不能估计更换会话的纯因果成本。模型 Minecraft 先验仍存在。边界是工具/工作流限制，不是 OS 安全隔离。前代的资源损失与未定位的合成异常均保留，不将所有失败解释为失忆。
